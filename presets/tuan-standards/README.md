# Tuan's Quality & Process Standards Preset

Preset quy chuẩn kỹ thuật cá nhân hóa cho **Phạm Đình Anh Tuấn (phamdinhanhtuan)**, thiết kế tương thích 100% với Spec Kit.

## Đặc điểm nổi bật
- **6 Nguyên tắc Kỹ thuật cốt lõi**:
  1. Đơn giản trước (Simplicity First)
  2. Bám sát đặc tả (Strict Spec Adherence)
  3. Kỷ luật kiểm thử (Test-Driven Discipline)
  4. Không giả định khi mơ hồ (Zero Ambiguity Tolerance)
  5. Kiểm soát từng bước có duyệt (Step-by-Step Approval)
  6. Giao tiếp & tài liệu Tiếng Việt chuẩn mực (Vietnamese Support)
- Tích hợp cổng `/speckit-clarify` tự động phát hiện mơ hồ và hỏi người dùng.
- Tương thích hoàn toàn với tất cả AI Coding Agents (Antigravity, Copilot, Cursor, Claude Code, Gemini CLI, v.v.).

## Cách sử dụng

Khi khởi tạo dự án mới:
```bash
specify init my-project --preset tuan-standards --integration agy
```

Hoặc thêm vào dự án hiện có:
```bash
specify preset add tuan-standards
```
